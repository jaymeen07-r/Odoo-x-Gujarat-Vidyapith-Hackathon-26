## ✨ Features

| Feature | Description |
|---|---|
| 🔐 **3-Step Firebase Auth** | Animated progress bar across a multi-step signup flow |
| 🗄️ **Firestore User Profiles** | Complete role-based data storage in the cloud |
| 🎨 **Glassmorphism UI** | Modern gradient + blur effects throughout the interface |
| 📱 **Fully Responsive** | Optimized for Desktop & Mobile |
| 🛡️ **Protected Routes** | Role-based dashboard access control |

## 🚀 Quick Start

**1. Clone the repository**
```bash
git clone https://github.com/jaymeen07-r/Odoo-x-Gujarat-Vidyapith-Hackathon-26.git
cd fleetmatrix
```

**2. Install dependencies**
```bash
npm install
```

**3. Run the development server**
```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
